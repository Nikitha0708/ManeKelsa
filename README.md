# 👷 Manekelsa – Self Employment Android App

Manekelsa is an Android application developed using Kotlin and Firebase to help daily wage workers and local customers connect easily.
The app supports self-employment opportunities by allowing workers to showcase their skills, availability, and contact details.

This project was developed as part of an **Android App Development using Generative AI** project.

---

# 📱 Features

* Worker Registration & Login
* Customer Login
* Firebase Authentication
* Real-time Worker Availability Status
* Worker Skill & Area Display
* Daily Wage Information
* Contact Details for Customers
* Multi-language Support (Kannada & English)
* Modern UI using Jetpack Compose
* Firebase Realtime Database Integration

# 🚀 How to Run the Project

1. Clone the repository
2. Open the project in Android Studio
3. Connect Firebase to the project
4. Sync Gradle files
5. Run the app on emulator or Android device

---

# 🔥 Firebase Setup

1. Go to Firebase Console
2. Create a new project
3. Add Android App
4. Download `google-services.json`
5. Place it inside:

app/google-services.json

6. Enable:

   * Authentication
   * Realtime Database
